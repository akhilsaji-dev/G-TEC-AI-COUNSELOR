## 📌 Overview

G-TEC AI Counselor is an intelligent virtual counselor designed to assist students in selecting the right courses based on their interests, educational background, and career goals.

The chatbot provides instant responses about:

- 📚 Available Courses
- 🎯 Career Guidance
- 💼 Job Opportunities
- ⏳ Course Duration
- 💰 Fee Information
- 🛠 Skills Covered
- 📈 Career Scope
- 🤖 AI-powered Conversation

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/akhilsaji-dev/G-TEC-AI-COUNSELOR-.git
```

Go to project folder

```bash
cd G_TEC_AI_Counselor
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

Run Migrations

```bash
python manage.py migrate
```

Start Server

```bash
python manage.py runserver
```

Open Browser

```
http://127.0.0.1:8000
```
